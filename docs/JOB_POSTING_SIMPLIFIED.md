# Senior Full-Stack Developer - AI Financial Platform (Remote)

**Company:** Midas AI
**Location:** Remote (US Timezones Preferred)
**Salary:** $140,000 - $180,000 + Equity
**Experience:** 5+ years

## About Us

Midas is building the AI-powered CFO for modern businesses. We integrate with QuickBooks, Zoho, and other accounting platforms to provide real-time financial intelligence through natural conversation. Small but mighty team (3 developers) taking on industry giants.

## What You'll Do

- Build and scale our AI-powered financial analysis platform
- Own features end-to-end from React frontend to AWS backend
- Optimize our LangChain multi-agent system
- Integrate with financial APIs (QuickBooks, banking providers)
- Mentor junior developers and shape technical direction

## Requirements

**Must Have:**

- 5+ years full-stack development experience
- Expert in Next.js 15, React 19, TypeScript
- Strong AWS experience (DynamoDB, Cognito, Lambda)
- Experience integrating LLMs (OpenAI, Anthropic, etc.)
- Track record of shipping production SaaS applications

**Nice to Have:**

- QuickBooks/Xero API experience
- Financial services background
- LangChain or agent frameworks
- Early-stage startup experience

## Tech Stack

- **Frontend:** Next.js 15, React 19, TypeScript, Tailwind CSS
- **Backend:** AWS (DynamoDB, Cognito), Redis, Next.js API Routes
- **AI/ML:** LangChain, Groq/OpenAI/Anthropic LLMs
- **Data Viz:** Chart.js, Recharts, ECharts

- Build cutting-edge AI in fintech
- Direct impact on product used by thousands
- No bureaucracy - ship code daily
- Remote-first with quarterly team gatherings
