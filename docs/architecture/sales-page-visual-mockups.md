## 15. Responsive Breakpoints Summary

### Desktop (>1280px)

- Full 4-column KPI layout
- Table + Detail panel side-by-side (2/3 + 1/3)
- All charts visible
- Tab bar horizontal

### Tablet (768px - 1280px)

- 2x2 KPI grid
- Table full width, detail panel overlays
- Charts side-by-side (2 columns)
- Tab bar horizontal

### Mobile (<768px)

- Stacked KPIs (1 column)
- Table scrolls horizontally
- Detail panel full-screen overlay
- Charts stack vertically
- Tab bar horizontal scroll
