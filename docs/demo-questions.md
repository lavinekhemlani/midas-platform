2. **Show memory in action**: Always include memory storage and retrieval to demonstrate continuity
3. **Mix data types**: Include questions that trigger different types of visualizations
4. **Highlight integration**: Show QuickBooks integration and learning system features

6. **Prepare follow-ups**: Have backup questions ready in case the demo goes faster than expected

8. **Highlight personalization**: Show how the AI remembers context and preferences
